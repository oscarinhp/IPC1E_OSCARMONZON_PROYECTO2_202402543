## Cómo verlos

- **En GitHub:** abrir cualquiera de los enlaces; Markdown muestra el texto,
  las imágenes y los diagramas Mermaid directamente.
- **En VS Code:** abrir un `.md` y pulsar **Ctrl+Shift+V** para vista previa.
  La visualización de Mermaid depende del soporte del editor; en GitHub se renderiza.
- Las capturas son PNG normales y se pueden abrir por separado.

Los manuales se entregan en Markdown; **no se han generado versiones PDF**.
Si el docente exige PDF, exportar los documentos revisados y comprobar que
conserven capturas y diagramas legibles antes de entregarlos.
